# Словарь прочитанного

Личный словарь незнакомых, старых и сложных слов из книг: значение, пометка, цитата с названием произведения и картинка.
Приложение на Streamlit, слова лежат в файле `words.yaml`.

## Что в папке
```
app.py            приложение
utils.py          загрузка, поиск, фильтры (без Streamlit)
words.yaml        все слова
images/           картинки к словам
tests/            проверки логики
requirements.txt  что установить
.streamlit/       оформление
```

## Запуск у себя на компьютере
```
pip install -r requirements.txt
streamlit run app.py
```
Откроется страница в браузере. Проверки логики: `python3 tests/test_utils.py`.

## Как добавить слово вручную
Открой `words.yaml` и добавь в конец запись по образцу. **Тексты бери в двойные кавычки**, иначе двоеточие или другие знаки внутри текста сломают файл (приложение покажет понятное предупреждение).

```yaml
- слово: "кибитка"
  значение: "крытая повозка на колёсах или на полозьях"
  пометка: "устар."
  произведение: "«Метель», А. С. Пушкин"
  цитата: "бросился в кибитку и закричал: пошёл!"
  картинка: "images/kibitka.jpg"
  картинка_источник: "Автор, лицензия, ссылка на страницу"
  добавлено: 2026-10-23
```
Обязательны только `слово` и `значение`. Одно слово не должно повторяться дважды.

## Картинки
- Клади файл в папку `images/`, в записи пиши путь `images/название.jpg`.
- Используй картинки в общественном достоянии или со свободной лицензией (например, из Wikimedia Commons) и сразу записывай автора, лицензию и ссылку в `картинка_источник`.
- Файлы лучше уменьшать до ширины около 800 px, так репозиторий не раздувается.
- Если картинки нет, приложение покажет серый квадрат с первой буквой слова.

## Публикация
1. Создай репозиторий на GitHub и загрузи в него все файлы этой папки (можно перетащить в окно сайта).
2. Зайди на share.streamlit.io, войди через GitHub, выбери «Create app», укажи свой репозиторий, ветку `main` и файл `app.py`.
3. Каждое изменение `words.yaml` или картинок в репозитории приложение подхватывает само (иногда с задержкой в минуту-другую).

## Дальше
Следующий этап: вкладка «Добавить слово» с паролем. Она будет сама сохранять слово и картинку в репозиторий через GitHub, поэтому токен хранится только в «Secrets» настроек приложения, а не в файлах (файл `.streamlit/secrets.toml` уже занесён в `.gitignore`).
