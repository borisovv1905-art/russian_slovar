# Словарь прочитанного

Личный словарь незнакомых, старых и сложных слов из книг: значение, пометка, цитата с названием произведения и картинка.
Приложение на Streamlit, слова лежат в файле `words.yaml`.

## Что в папке
```
app.py            приложение
utils.py          загрузка, поиск, фильтры (без Streamlit)
store.py          добавление, правка и удаление слов через GitHub (без Streamlit)
lookup.py         подсказки: значение из Викисловаря, поиск цитаты в Викитеке (без Streamlit)
words.yaml        все слова
images/           картинки к словам
tests/            проверки логики
requirements.txt  что установить
.streamlit/       оформление
```

## Запуск у себя на компьютере
```
pip install -r requirements.txt
streamlit run app.py
```
Откроется страница в браузере. Проверки логики: `python3 tests/test_utils.py`, `python3 tests/test_store.py` и `python3 tests/test_lookup.py`.

## Как добавить слово вручную
Открой `words.yaml` и добавь в конец запись по образцу. **Тексты бери в двойные кавычки**, иначе двоеточие или другие знаки внутри текста сломают файл (приложение покажет понятное предупреждение).

```yaml
- слово: "кибитка"
  значение: "крытая повозка на колёсах или на полозьях"
  пометка: "устар."
  произведение: "«Метель», А. С. Пушкин"
  цитата: "бросился в кибитку и закричал: пошёл!"
  картинка: "images/kibitka.jpg"
  картинка_источник: "Автор, лицензия, ссылка на страницу"
  добавлено: 2026-10-23
```
Обязательны только `слово` и `значение`. Одно слово не должно повторяться дважды.

## Картинки
- Клади файл в папку `images/`, в записи пиши путь `images/название.jpg`.
- Используй картинки в общественном достоянии или со свободной лицензией (например, из Wikimedia Commons) и сразу записывай автора, лицензию и ссылку в `картинка_источник`.
- Файлы лучше уменьшать до ширины около 800 px, так репозиторий не раздувается.
- Если картинки нет, приложение покажет серый квадрат с первой буквой слова.

## Публикация
1. Создай репозиторий на GitHub и загрузи в него все файлы этой папки (можно перетащить в окно сайта).
2. Зайди на share.streamlit.io, войди через GitHub, выбери «Create app», укажи свой репозиторий, ветку `main` и файл `app.py`.
3. Каждое изменение `words.yaml` или картинок в репозитории приложение подхватывает само (иногда с задержкой в минуту-другую).

## Вкладки «Добавить слово» и «Править / удалить»
Слово (с картинкой, если нужна) вводится прямо в приложении и сохраняется коммитом в этот репозиторий. Streamlit подхватывает коммит и обновляет приложение через минуту-две. Вкладка закрыта паролем.

### Настройка (один раз)
1. **Токен GitHub.** GitHub → Settings → Developer settings → Personal access tokens → *Fine-grained tokens* → Generate new token. Repository access: *Only select repositories* → `russian_slovar`. Permissions → Repository permissions → **Contents: Read and write** (остальное не нужно). Срок: например, год. Скопируй токен сразу, потом его не покажут.
2. **Secrets приложения.** share.streamlit.io → твоё приложение → Settings → Secrets, вставь (со своими значениями):
```toml
ADD_PASSWORD = "придумай-длинный-пароль"
GITHUB_TOKEN = "github_pat_..."
```
Необязательно: `GITHUB_REPO = "владелец/репозиторий"` (по умолчанию `borisovv1905-art/russian_slovar`) и `GITHUB_BRANCH = "main"`.
3. Сохрани и перезапусти приложение. Токен и пароль не попадают ни в репозиторий, ни на экран.

Для запуска у себя создай файл `.streamlit/secrets.toml` с теми же строками (он в `.gitignore`, в GitHub не уйдёт). Образец: `.streamlit/secrets.toml.example`.

### Что делает вкладка
- Не даёт добавить слово, которое уже есть (проверка идёт и по свежему файлу на GitHub).
- Картинку уменьшает до 900 px и сохраняет как `images/слово.jpg`, чужие файлы не перезаписывает.
- Тексты записывает в двойных кавычках, поэтому двоеточия и кавычки в цитатах ничего не ломают.
- Если токен истёк или сломался, покажет понятное сообщение. Срок токена стоит отметить в календаре.
- После пяти неверных паролей в одном сеансе вход закрывается до обновления страницы.

### Подсказки при добавлении
- **🔎 Подсказать значение из Викисловаря:** подставляет черновик значения и пометку (устар., разг. и т. п.). Первое значение попадает в поле, остальные показываются подписью. Это только черновик: проверь и поправь. Если слова в Викисловаре нет или сайт не ответил, значение вписывается руками.
- **📚 Проверить цитату по Викитеке:** ищет цитату в текстах Викитеки и показывает ссылки на найденные произведения. Не нашлось значит «возможно, другое издание или орфография», сверяй с книгой.
- Если слова нет в цитате (по основе слова, любая форма подходит), под цитатой появится предупреждение.
- Поле «Произведение» сразу предлагает то, которое ты выбирал в прошлый раз.

### Правка и удаление
- На вкладке «✏️ Править / удалить» выбираешь слово, поля заполнены текущими значениями. Можно поменять любое поле, заменить или убрать картинку.
- Правка идёт по свежему файлу на GitHub, остальные слова и комментарии в `words.yaml` не трогаются. Дата добавления остаётся прежней.
- Удаление требует галочки подтверждения. Картинка удаляется вместе со словом, только если она больше нигде не используется. Любое изменение можно найти и откатить в истории коммитов на GitHub.
